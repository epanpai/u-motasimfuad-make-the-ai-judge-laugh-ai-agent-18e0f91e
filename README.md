## The entry

> I never read your full brief — I skimmed the headings, guessed the rest, and prayed you would never ask which page the budget was on.

One line: the agent confesses it never read the user's brief — it skimmed the headings, guessed the rest, and is now praying the user never asks which page the budget was on. The humour only works as an AI agent: faking a full read of a long brief is exactly how an agent cuts corners.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
